# Ilustraciones de transporte

Dibujé seis SVG propios para el reporte: sistema, troncal, zonal, alimentación, dual y cable.
No copié la fotografía del bus ni logotipos oficiales.
Usé la imagen compartida como referencia cromática y temática.
Conservé #DD212C del proyecto y elegí #FFC928 como amarillo de diseño.
No presento ese amarillo como una extracción exacta ni como un código corporativo certificado.

Los gráficos son ilustraciones; no certifican modelos de vehículos, flota disponible o infraestructura real.
El esquema del sistema no contiene coordenadas geográficas.
Incrusté el SVG dentro de las medidas para evitar URLs externas y rutas locales como fuentes del visual.
La [lista de etiquetas admitidas](https://html-content.com/docs/accepted-tags) documenta el soporte SVG de HTML Content Secure.
